# 🌿 Opal Haven – Where Heritage Meets Serenity

**Opal Haven** is a modern, responsive hotel landing page designed to showcase the elegance of heritage hospitality. This project blends sleek aesthetics with smooth interactivity to provide an immersive user experience.

---

## 🌟 Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.  
- **Hero Section:** Stunning introductory visuals with a clear Call-to-Action (CTA).  
- **Gallery:** Beautifully curated hotel images to showcase heritage and comfort.  
- **Booking Form:** Simple and elegant form for reservations.  
- **Smooth Scroll & Animations:** Enhances user engagement and visual appeal.

## 🚀 How to Run Locally

1. **Clone the repository:**
```bash
git clone https://github.com/YOUR_USERNAME/opal-haven.git
```

2. **Navigate into the project directory:**
```bash
cd opal-haven
```

3. Open the index.html in your preferred browser
open index.html
